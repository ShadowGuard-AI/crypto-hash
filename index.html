Purpose, entered first

The tool prints the hex digest of a text string or of a file. It builds on the Python standard library hashlib alone. It has no subcommands, and it offers no verify mode, so a reader who wants a check must hash again and compare the printed line with their own eyes.

The three printed examples

The second block of the record shows the three printed examples from the README without alteration: the string example with the default algorithm, the file example naming the md5 algorithm, and the quiet example. The rule the examples assume is that either the text option or the file option is given and never both together, since the parser refuses the pair.

Controls, in parser order

The text option -t and --text accepts a string and treats an empty string as a real input with a well defined digest. The file option -f and --file accepts a path and causes the file to be read in blocks of 4096 bytes so that size alone never fills memory. The algorithm option -a and --algorithm defaults to sha256 and its choices are the fixed length digests offered by hashlib, with the SHAKE names withheld because their hex form needs a length this tool never supplies. The quiet option -q and --quiet silences logging for the whole process, error lines included, leaving the exit code as the only sign of a failed run.

Endings, recorded plainly

A good run prints a single line that begins Hashed text or Hashed file according to the input kind. A missing file or a bad algorithm ends the run at exit 1, and a call with neither input prints the help text before it also ends at exit 1.

## Crypto Hash

### Project Description

Crypto Hash prints the hex digest of a text string or of a file's
contents, using Python's standard library `hashlib`. It has no
third-party dependencies and no subcommands; there is no verify mode,
so checking a file means hashing it and comparing the printed digest
yourself.

### Usage Examples

```
# SHA-256 of a string (sha256 is the default algorithm)
python3 main.py --text "Hello World"

# MD5 of a file's contents
python3 main.py --file file.txt --algorithm md5

# Quiet mode prints only the digest line
python3 main.py --text "Hello World" --quiet
```

Give either `--text` or `--file`, not both. The SHAKE algorithms are
not offered: their digests need a length argument, which this tool does
not take.
